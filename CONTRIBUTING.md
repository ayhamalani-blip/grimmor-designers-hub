# Contributing

## Branches

Use `feature/`, `fix/`, `docs/`, or `chore/` prefixes. Keep `main` as the integration branch.

## Approval

Every user-visible change requires an approved `AL-XXXX` entry in `APPROVAL_LOG.md` before implementation. Keep work within the recorded scope.

## Pull requests

Use the repository pull-request template. Include the approval entry, scope boundaries, validation evidence, and review notes. Run static verification before requesting merge.
