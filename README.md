# Grimmor Designers Hub

Public static reference site for Grimmor brand, logo, motion, opening-film, and design-system guidelines.

## Local preview

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Open `http://localhost:4173/`.

## Workflow

- Document approved scope in `APPROVAL_LOG.md` before implementation.
- Work on a `feature/`, `fix/`, `docs/`, or `chore/` branch.
- Run the static verification workflow, open a pull request, and merge only after the approved scope and checks are complete.

## Current status

Live on GitHub Pages from the `main` branch root.
